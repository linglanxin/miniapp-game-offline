# 案例《一棍打天下》

- 微信和 B 站分享页用于核对身份，另找到内容一致的中文 Unity WebGL 2.6.0 公开构建。该构建包含主数据及 592 个 Addressables 资源包。核对了同款开场、恐龙时代、装备、商城及领奖。源项目、平台存档通用性和全流程通关范围需要独立验证。
- 名称含 NoAd 的构建仍会出现一张模拟插屏。补丁使 `IAA_ShowInterstitialAd` 在存储继续回调后走原生关闭。激励视频路线已能直接调用原生成功回调，因此保留发奖和计数代码，再实测精良宝箱、反复计数的礼包、100 骨头、10 宝石和立即进化。
- 免费宝石到账但商店返回键失效，原因来自两处。广告调用先设了暂停，跳过后未恢复。余额变化还会尝试显示商店下方的地图背包引导。先去掉该离线奖励特有的暂停，再让地图背包的引导检查在菜单画布关闭时生效。复测余额 3→13、返回地图和重新打开后余额保持。
- 实际新档需要推进才能看到背包。将原生背包的显示条件提前到开场穿越完成后，用原生版本标记避免在银河开场期间两层引导同时出现。初次打开由原游戏引导开免费宝箱、装备并查看指环、返回地图，再次打开背包后点底部紫色小店。Android 15 飞行模式下从 0 宝石进入商城，领到 10 颗，重开后仍为 10。
- Windows 保持同一环回地址和浏览器配置。Android 用同一安装包名、签名和虚拟 HTTPS origin 安装。安卓版 DPR 上限从 1.5 调到 2，样本地表资源为 512×512 ASTC，原贴图质量决定可见细节上限。
- 方法名和具体路径用于理解这个已验证构建。其他构建先从符号、方法体和画面重新定位，独立确定目标，保留原版副本。
